# Telegram Bot и Telegram Mini App: Трекер событий

Полнофункциональный Telegram-бот и встроенное веб-приложение (Telegram Mini App) для отслеживания времени до важных дат и событий с живыми таймерами, шкалой прогресса и push-уведомлениями.

## Стек и архитектура

- Backend: Python 3.11+, aiogram 3.x (асинхронный Telegram-фреймворк), APScheduler (периодические рассылки и проверка таймеров), aiosqlite (асинхронный SQLite).
- Frontend (Mini App): Легковесный стек HTML5, CSS3 Glassmorphism (темная тема #0A0A0C, размытие 16px, неоновые градиенты), чистый JavaScript с поддержкой Telegram WebApp SDK, тактильным откликом HapticFeedback и векторными иконками Lucide.
- Сервер: Встроенный aiohttp HTTP-сервер, запущенный в одном цикле событий (asyncio event loop) с Telegram-ботом. Обеспечивает работу REST API и раздачу статики Mini App без задержек и проблем с CORS.

## Установка и запуск

### 1. Клонирование и установка зависимостей

Убедитесь, что установлен Python 3.11 или новее.

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте файл конфигурации:

```bash
cp .env.example .env
```

Откройте `.env` и укажите параметры:

- `BOT_TOKEN`: токен вашего бота, полученный у @BotFather в Telegram.
- `WEBAPP_URL`: публичный HTTPS-адрес вашего веб-приложения (см. настройку туннеля ниже).
- `HOST`: 0.0.0.0
- `PORT`: 8080
- `TIMEZONE`: Europe/Moscow
- `DIGEST_HOUR`: 10
- `DIGEST_MINUTE`: 0

### 3. Настройка локального туннеля (ngrok) для Telegram Mini App

Telegram требует обязательное использование защищенного протокола HTTPS для всех WebApp. Для локальной разработки используйте ngrok:

1. Установите ngrok (https://ngrok.com) или аналогичный инструмент (например, localtunnel / pinggy).
2. Запустите туннель на порт 8080:

```bash
ngrok http 8080
```

3. Скопируйте полученный HTTPS-адрес (например, `https://abc-123.ngrok-free.app`).
4. Вставьте этот адрес в переменную `WEBAPP_URL` в файле `.env`.

### 4. Настройка кнопки меню в @BotFather

Чтобы кнопка Mini App отображалась слева от поля ввода в чате Telegram:

1. Откройте чат с @BotFather в Telegram.
2. Отправьте команду `/mybots` и выберите вашего бота.
3. Перейдите в раздел `Bot Settings` -> `Menu Button` -> `Configure menu button`.
4. Вставьте ваш публичный HTTPS-адрес из ngrok.
5. Укажите название кнопки (например, `Открыть приложение` или `Напоминания`).

### 5. Запуск бота и сервера

Запустите главный файл проекта:

```bash
python main.py
```

После запуска в консоли появится подтверждение старта HTTP-сервера и готовности бота к обработке входящих сообщений.

## Функционал

### Telegram Mini App

- Главный экран:
  - Список активных событий с тикающими счетчиками реального времени.
  - Динамическая шкала прогресса времени (от момента создания до срока цели).
  - Модальное окно создания и редактирования событий.
  - Кастомный интерактивный календарь с быстрым выбором (+1, +7, +30 дней).
  - Переключатель точного времени с плавным выездом селекторов часов и минут.
  - Удаление и редактирование карточек в один клик.
  - Тактильный отклик Telegram HapticFeedback при всех ключевых действиях.

### Telegram-бот

- Команда `/start`: приветствие и запуск Mini App либо переход к сценариям в чате.
- Команда `/add`: пошаговое создание напоминания через inline-кнопки (название -> дата -> время -> сохранение).
- Команда `/events` или `/list`: вывод активных напоминаний с кнопками удаления.
- Ежедневный дайджест: автоматическая отправка сводки в 10:00 с подсчетом оставшихся дней и часов.
- Точные таймеры: фоновая проверка каждые 30 секунд. При наступлении точного срока бот мгновенно отправляет уведомление и переводит событие в статус завершенных.
